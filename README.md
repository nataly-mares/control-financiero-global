# Global Financial Control 📊

## ✅ Project Description
This project consists of developing an interactive financial dashboard in Power BI to analyze global economic performance. The dashboard allows visualizing key indicators related to revenue, expenses, and net profit broken down by region, period, and product type, facilitating financial analysis and data-driven decision-making.

## ✅ Objective
Design a dynamic and interactive dashboard that allows to:
- Analyze the company's total revenue
- Evaluate the behavior of operating expenses
- Monitor net profit in real time
- Analyze financial performance by geographic region
- Evaluate sales performance by product type and period

## ✅ Visualizations Included
- Revenue, expenses, and profit by region (comparative bar charts)
- Profitability breakdown by product type
- Interactive filters by time period and multi-region selection
- Main KPIs: Total revenue, Total expenses, and Net profit

## ✅ Tools Used
- Power BI / Power BI Service
- Power Query
- Data modeling and DAX measures
- Interactive visualizations and slicers

## ✅ Results
An interactive dashboard was developed for comprehensive financial monitoring.
The analysis made it possible to accurately identify the regions and product types with the highest contribution to net profit.
Interactive visualizations improve the understanding of economic trends and budget control.

## ✅ How to Use the Project
Download the file from the repository
Open the file using Power BI
Explore the visualizations and use the interactive filters by region and period

# ✅ Descripción del proyecto
Este proyecto consiste en el desarrollo de un dashboard financiero interactivo en Power BI para analizar el rendimiento económico global. El tablero permite visualizar indicadores clave relacionados con ingresos, gastos y ganancias netas desglosados por región, período y tipo de producto, facilitando el análisis financiero y la toma de decisiones basada en datos.

## ✅ Objetivo
- Diseñar un dashboard dinámico e interactivo que permita:
- Analizar los ingresos totales de la empresa
- Evaluar el comportamiento de los gastos operativos
- Monitorear la ganancia neta en tiempo real
- Analizar el rendimiento financiero por región geográfica
- Evaluar el desempeño de ventas por tipo de producto y período

✅ Visualizaciones incluidas
- Ingresos, gastos y ganancia por región (gráficos de barras comparativos)
- Desglose de rentabilidad por tipo de producto
- Filtros interactivos por período temporal y selección múltiple de regiones
- KPIs principales: Ingresos totales, Gastos totales y Ganancia neta

✅ Herramientas utilizadas
- Power BI / Power BI Service
- Power Query
- Modelado de datos y medidas DAX
- Visualizaciones interactivas y segmentaciones

✅ Resultados
Se desarrolló un dashboard interactivo para el monitoreo financiero integral.
El análisis permitió identificar con precisión las regiones y tipos de producto con mayor contribución a la ganancia neta.
Las visualizaciones interactivas mejoran la comprensión de las tendencias económicas y el control presupuestario.

✅ Cómo utilizar el proyecto
Descargar el archivo del repositorio
Abrir el archivo utilizando Power BI
Explorar las visualizaciones y utilizar los filtros interactivos por región y período
